Initial sample history is zero after reset.

The sample-history registers d0/d1/d2 are signed 10-bit, matching the Week 4 baseline.
The signed 8-bit x_in value is sign-extended to 10 bits before being stored.

Main parallel-FIR hold check:
After accepting x=1 and x=2, an invalid cycle with x_in=99 must NOT shift d0/d1/d2,
must deassert valid_out, and must leave the previous y_out value held but invalid.

Main pipelined-FIR bubble check:
Accepted sequence: 1, 2, [invalid 99], 3, 4, 5.
- The invalid x=99 cycle must hold d0/d1/d2 and p0_s1/p1_s1/p2_s1.
- The result for accepted x=2 still appears on that bubble edge because it was already in Stage 1.
- One cycle later valid_out must be 0, creating the delayed output bubble.
- Valid traffic then resumes correctly for x=3,4,5 and the final result drains one cycle later.

Signed boundary regression:
Repeated x=-128 reaches the exact FIR lower bound:
accepted outputs = [-128, -384, -512].
Both Week 5 architectures must produce these values exactly; the pipelined version produces them one cycle later.
